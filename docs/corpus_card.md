# Картка корпусу

Навчальний корпус Domain Knowledge Hub для умовного машинобудівного підприємства «Метал-Деталь». 20 синтетичних документів, 200 фрагментів, українська мова. Поля: doc_id, title, section, type, date, sensitivity, source_url, text.

## Джерела та ліцензії
Усі тексти створені спеціально для навчальної роботи, не скопійовані з реальної документації. Їх можна поширювати в межах цього навчального пакета як CC0-1.0. `synthetic://` — внутрішній ідентифікатор, не зовнішнє джерело.

## Очищення
Нормалізація пробілів; вилучення повторюваних колонтитулів, номерів сторінок і навігації (у вихідному синтетичному наборі відсутні); перевірка непорожнього тексту та метаданих.

## Чутливість
Кожен фрагмент має `sensitivity=public_training`. Персональні дані, комерційні таємниці, паролі й реальні показники не включені.

## Прогалини
Немає реальних паспортів верстатів, креслень, допусків, режимів різання, сертифікатів матеріалу та журналів виробництва. Матеріал не замінює офіційні інструкції.
