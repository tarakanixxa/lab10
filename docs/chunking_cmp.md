# Chunking
Реалізовано fixed-size (260 символів, overlap 40), structure-aware (один змістовий запис на chunk), semantic approximation (групування речень до 420 символів). Для цього корпусу початково обирається structure-aware, бо записи вже є атомарними. Порівняльні Recall@5 і середній розмір контексту слід заповнити після запуску всіх трьох індексів на одному gold-наборі; неперевірені значення не наводяться.
