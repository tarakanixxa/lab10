# Hybrid search
BM25 поєднується з dense retrieval через RRF із k=60. Top-30 кандидатів rerank-яться cross-encoder моделлю `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` до top-5. Реалізовано pre-filter за type, sensitivity, date_from/date_to. Сценарії перевірки: (1) точний термін «маршрутна карта» — очікувана перевага BM25; (2) перефразування про відведення тепла — потенційна перевага dense; (3) запит про партію і простежуваність — можливий виграш RRF; (4) рідкісний код — можливий програш dense проти BM25. Це гіпотези для перевірки, а не заявлені виміряні результати.
